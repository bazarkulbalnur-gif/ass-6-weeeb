# Assignment #6. jQuery (Selectors, Effects, Animations)

**Student:** Bazarkul Balnur

## Description

A multi-page website that demonstrates the basics of jQuery: selectors, effects, DOM manipulation and animations.
The design is made in sky blue colors with floating bubbles and flowers in the background.
Every page has a navigation bar (navbar) that links to the different parts of the assignment.

## Pages and tasks

| Page | Part | Tasks |
| --- | --- | --- |
| `index.html` | Part 1. Getting Started with jQuery | Task 0 (Setup), Task 1 (Selectors & CSS) |
| `effects.html` | Part 2. jQuery Effects | Task 2 (Visibility), Task 3 (Fade), Task 4 (Slide) |
| `dom.html` | Part 3. DOM Manipulation | Task 5 (Add & Remove), Task 6 (Attributes), Task 7 (Form) |
| `animations.html` | Part 4. Animations | Task 8 (Basic), Task 9 (Sequential), Task 10 (Combined) |
| `project.html` | Part 5. Mini Project | Task 11 (Bouncing Ball) |

## How to run

1. Download or clone the repository.
2. Open `index.html` in any modern browser (an internet connection is needed to load jQuery from the CDN).
3. Use the navbar to move between the pages.
4. Open the browser console (F12) on the first page to see the message `jQuery is ready!`.

## How to publish with GitHub Pages

1. Create a new repository on GitHub and upload all files of the project.
2. Open **Settings → Pages**.
3. In **Source** choose **Deploy from a branch**, select the `main` branch and the `/ (root)` folder, then press **Save**.
4. After a minute the site will be available at `https://<username>.github.io/<repository-name>/`.
